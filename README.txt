Security+ PBQ Simulator
=======================
EASIEST (no setup): open pbq-sim-final.html, click "Choose files", select one or more
.json question sets, then Begin.

GITHUB PAGES (auto-loads everything):
1. Put pbq-sim-final.html and the sets/ folder in a GitHub repo (rename the html to index.html if you like).
2. Settings > Pages > deploy from the main branch.
3. To add a new question set: drop the .json into sets/ and add its filename to sets/manifest.json.
   The page loads everything listed there automatically.

Note: auto-loading only works over http(s) (GitHub Pages or a local server), not by double-clicking the file.
